# 已确认的需求与方案

2026-10-03，用户确认后开始实施。

1. A 弹出工具箱：一个可拖动入口，点击展开两列图标和名称。
2. 支持插件以及酒馆助手全局、角色卡、预设脚本产生的悬浮球和长条悬浮按钮。
3. 原入口隐藏，插件和脚本继续运行，点击工具箱项触发原功能，面板保持原样。
4. 默认选中工具后收起；点击外部、关闭按钮或 Esc 收起。
5. 自动发现候选，首次确认后才隐藏；漏检可用点选模式添加。
6. 识别规则保存为配置，日常新增无需编辑源码。
7. 刷新、角色或预设切换、按钮重建时重新匹配。不存在的入口暂时不显示，规则保留。
8. 稳定脚本／按钮 ID 优先，避免同名混用；歧义时不隐藏。
9. 支持命名、排序、保留在外面、移除、一键恢复。
10. 深色半透明、金色描边、圆角，兼顾鼠标和触屏，入口位置记忆。
11. 程序触发异常时恢复原入口。特殊隔离控件不能承诺通用兼容。
12. 在当前目录创建插件目录、独立 Git 仓库，并在 Steam Deck 51004 酒馆测试。无需编译；若有环境需求，可使用 Steam Deck。

实际入口名称／归属以页面核验为准，不能将脚本列表内所有脚本都当作悬浮球。完整弹窗、装饰和后台脚本不自动收纳。
