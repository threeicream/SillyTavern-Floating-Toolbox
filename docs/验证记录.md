14. 入口变为完整面板时保持可见。

## 检查与边界

- 本地 Node.js 对入口、核心模块、验证脚本和验证服务器执行 `node --check`，全部通过。
- Steam Deck 运行容器内对三个 JavaScript 运行模块执行 `node --check`，全部通过。五个线上运行文件与本地 SHA-256 一致。
- 本地 npm 启动器的运行时路径缺失，使用相同的 Node.js 检查命令完成检查；插件无需 npm 安装或编译。
- 禁用后的恢复、歧义保护、iframe／Shadow DOM 兼容均有验证页覆盖。跨域 iframe、封闭 Shadow DOM、静默拒绝程序代点的控件未承诺通用支持。
- 无远程 Git 仓库；日后发布仓库后可通过酒馆「安装扩展」使用仓库 URL 安装。
