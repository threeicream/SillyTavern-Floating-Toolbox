# 验证记录

## 0.1.4：Shadow DOM 扫描与点选（2026-10-03）

51002 的「战斗目录」「行动选项」都位于开放 Shadow DOM 内，外层宿主浮动定位，内部按钮使用普通布局。旧版扫描未跨过 Shadow 边界查找浮动宿主；点选时主文档捕获到了内部按钮，却用监听器所在根的路径保存，导致保存时误报失效。

扫描现在可跨 Shadow 宿主查找浮动祖先。点选从按钮实际所在根选择完整路径，保留 iframe 与嵌套 Shadow 层级；点选期间新建、未登记路径的根仍会阻止原点击并提示重新点选。保持只在点击扫描时发现新入口。

独立浏览器验证 **26/26 通过**，新增覆盖浮动 Shadow 宿主内的普通按钮扫描／收纳／触发、iframe 内嵌套 Shadow 的点选保存及不执行原操作、点选期间新建 Shadow 根的误触保护。JavaScript 语法及 Git 空白检查通过。

用户要求取消持续扫描。当前版本只通过「扫描新入口」按钮发现候选，没有定时扫描、MutationObserver 或聊天／预设变化触发的扫描。已收纳项在初始化、打开工具箱和用户操作时按保存规则核对。
